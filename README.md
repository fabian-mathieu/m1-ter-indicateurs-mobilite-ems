Contient les données relatives à la création d'un tableau de bord pour la mobilité urbaine dans l'Eurométropole de Strasbourg (projet de TER - M1 OTG).

Réalisé en deux mois, ce travail visait à implémenter une cinquantaine d'indicateurs d'abord envisagés pour le projet SuMo-Rhine (2018-2021).

Le dossier *documents_de_travail* contient l'état de l'art des systèmes d'indicateurs que j'ai réalisé, ainsi que les sources de données utilisées.

Le dossier *notebook* contient le fichier .ipynb, qui est un notebook python contenant les méthodes de calcul des indicateurs.

Plus de détails sont visibles dans le mémoire réalisé vers la fin du projet.

Le notebook actuel est laissé "tel quel" depuis la fin du TER, mais je prévois d'y apporter quelques corrections !
